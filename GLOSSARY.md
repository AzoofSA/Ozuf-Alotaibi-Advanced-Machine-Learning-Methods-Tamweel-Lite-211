# قاموس المصطلحات / Glossary

## Baseline — خط الأساس

مرجع بسيط تقارن به النماذج اللاحقة.

A simple reference used to compare later models.

## Boosting — التعزيز

إضافة متعلمين بالتتابع لتحسين دالة الهدف.

Sequentially adding learners to improve an objective.

## Leakage — تسرب البيانات

استخدام معلومات لم تكن متاحة عند لحظة القرار.

Using information unavailable at decision time.

## OOF — تنبؤ خارج الطية

تنبؤ لصف من نموذج لم يتدرب على ذلك الصف.

A prediction from a model not trained on that row.

## Threshold — عتبة القرار

قيمة تحول احتمال الخطر إلى إشارة قرار.

A cutoff that turns risk probability into a decision flag.

## False negative — تعثر لم يُرصد

حالة متعثرة لم يرفع النموذج لها إشارة خطر.

A default case that the model did not flag.

## False positive — إنذار خاطئ

حالة سليمة رفع النموذج لها إشارة خطر.

A non-default case that the model flagged.

## Calibration — معايرة الاحتمال

مقارنة الاحتمالات بالتكرار الفعلي للنتائج.

Comparing predicted probabilities with observed frequencies.

## SHAP — إسهام الخصائص

تفسير إسهام كل خاصية ضمن وحدة خرج محددة، وليس دليل سببية.

Feature contributions in a defined output space, not proof of causality.

## Ensemble — تجميع النماذج

الجمع بين تنبؤات نماذج؛ فائدته تحتاج دليلًا.

Combining model predictions; the benefit needs evidence.

## Model Card — بطاقة النموذج

توثيق الغرض والبيانات والمنهج والنتائج والقيود.

Documentation of purpose, data, method, results and limits.

## Reproducibility — قابلية إعادة الإنتاج

إعادة بناء النتائج من البيانات والإعدادات والنسخة المحددة.

Rebuilding results from specified data, settings and code version.

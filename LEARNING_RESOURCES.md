# فيديوهات ومراجع تساعدك / Learning resources

اختر المرجع الذي تحتاجه؛ المشاهدة اختيارية ولا تضيف متطلبات أو درجات. الفيديوهات بالإنجليزية، ويصاحب كل منها توجيه بالعربية. استخدم الترجمة النصية المتاحة في YouTube إن احتجتها. تبقى تعليمات مختبرات الدورة وإصداراتها المرجع للتطبيق؛ قد تختلف الواجهة في التسجيلات القديمة. لا يلزم شراء كتاب أو اشتراك أو إنشاء حساب سحابي إضافي تظهر إعلاناته في أي فيديو.

These optional English-language videos support the Arabic course guides. Use available captions, and follow the course notebooks for current steps and pinned package versions. No purchase or additional cloud account is required.

تحققنا في 2026-10-02 من هوية الفيديو والقناة والمدة وحالة إتاحته العامة في YouTube. قد تتغير الإتاحة أو الترجمة بحسب المنطقة. [سجل المراجع](resources/videos.yml) يحفظ بيانات التحقق؛ لا تعني هذه المراجعة ضمان الإتاحة الدائمة.

## فيديوهات مختارة / Selected videos

### إنشاء مستودع وفهم ملفات مشروعك

[How to create your first GitHub repository: A beginner's guide | Tutorial](https://www.youtube.com/watch?v=-RZ03WHqkaY) · GitHub · 9:31 · beginner

تعرف على المستودع والملفات قبل إنشاء نسختك من قالب الدورة.

Understand repositories and files before creating your own project from the course template.

### البداية مع Google Colab

[Get started with Google Colaboratory (Coding TensorFlow)](https://www.youtube.com/watch?v=inN8seMm7UI) · TensorFlow · 3:10 · beginner

تعرف على الخلايا وتشغيل Python في المتصفح. واجهة الفيديو قديمة؛ اتبع دليل الدورة للخطوات الحالية.

Learn cells and browser-based Python. This older video introduces concepts; follow the course guide for current steps.

### فهم GitHub Actions

[How to use GitHub Actions | GitHub for Beginners](https://www.youtube.com/watch?v=BQrohJ3PT7I) · GitHub · 8:04 · beginner

افهم مكان التشغيل وقراءة النتيجة؛ استخدم workflows الموجودة في قالب الدورة.

Locate runs and read their results. Use the workflows already included in your course template.

### فكرة Gradient Boosting

[Gradient Boost Part 1 (of 4): Regression Main Ideas](https://www.youtube.com/watch?v=3CC4N4z3GJc) · StatQuest with Josh Starmer · 15:52 · intermediate

ابدأ بفكرة تصحيح الأخطاء المتتابع في مثال انحدار، ثم اربطها بتصنيف اليوم الأول.

Build intuition from a regression example, then connect it to classification in day 1.

### XGBoost للتصنيف

[XGBoost Part 2 (of 4): Classification](https://www.youtube.com/watch?v=8b1JEDvenQU) · StatQuest with Josh Starmer · 25:17 · intermediate

راجع كيف تتحول الأشجار إلى احتمال في التصنيف؛ مثال تعليمي وليس حل مشروعك.

Review how boosted trees produce classification probabilities; this is not a solution to your project.

### فهم التحقق المتقاطع

[Machine Learning Fundamentals: Cross Validation](https://www.youtube.com/watch?v=fSytzGwwBVw) · StatQuest with Josh Starmer · 6:04 · intermediate

راجع فكرة الطيات؛ أضف إليها قيود الزمن والعملاء ونضج الهدف في مختبر اليوم الثاني.

Review folds, then add the time, customer and target-maturity constraints from day 2.

### ROC وعتبة القرار وPrecision–Recall

[ROC and AUC, Clearly Explained!](https://www.youtube.com/watch?v=4jRBRDbJemM) · StatQuest with Josh Starmer · 16:17 · intermediate

قارن المقاييس وتأثير العتبة؛ ركز أيضًا على الجزء الأخير عن Precision–Recall.

Compare metrics and thresholds, including the final section on precision–recall.

### SHAP من صاحب الطريقة

[The Science Behind InterpretML: SHAP](https://www.youtube.com/watch?v=-taOhqkiuIo) · Microsoft Developer · 11:46 · intermediate

استمع إلى Scott Lundberg عن إسهام الخصائص. الشرح لا يثبت السببية، ولا يتطلب حساب Azure.

Hear SHAP creator Scott Lundberg explain feature contributions. Explanations do not establish causality; no Azure account is required.

### المعايرة والقرار الحساس للتكلفة

[KEYNOTE: Olivier Grisel - Handling predictive uncertainty in Machine Learning | PyData Paris 2024](https://www.youtube.com/watch?v=-gYnfA0e5ic) · PyData · 44:27 · advanced

محاضرة اختيارية تجمع جودة الاحتمال وقرار العتبة؛ طبّق سياسة الدورة التعليمية 10FN+FP وسقف12%.

An optional lecture connecting uncertainty, calibration and decisions. Apply the course’s educational 10FN+FP loss and 12% capacity.

### تجميع Stacking للأحداث النادرة

[Using a Stacking Model Ensemble Approach to Predict Rare Events | SciPy 2019 | Susan Yuhou Xia](https://www.youtube.com/watch?v=6oD5K0x1k7c) · Enthought · 26:05 · advanced

راجع فكرة النموذج الجامع ثم ناقش ضرورة OOF والاختبار الصادق في مشروعك؛ لا تفترض أن التجميع سيفوز.

Review stacking, then examine OOF predictions and honest validation in day 5. Ensembling is not guaranteed to win.
